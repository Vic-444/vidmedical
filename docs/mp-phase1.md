# VidMedical — MP Phase 1 (Outbound)

**Goal:** 2–3 trial conversations → 1–2 paid singles → retainers.  
**Mode:** Push only. You send; AI drafts. No auto-send. One link: https://vidmedical.com

## Beachhead

| Field | Rule |
| --- | --- |
| Niche | Cosmetic / implant dentistry |
| Markets | US, UK, CA, AU, UAE (English, cash-pay) |
| Keep if | High-ticket offer · posting talking-head Reels (~last 60 days) · weak visuals (phone + captions) · small private practice |
| Skip | Big DSOs · no recent video · non-English primary |

## Daily cadence

1. Find **5–10** qualified clinics (one city/cluster).
2. Send **5–10** short plain-text emails same or next day.
3. Optional matching IG DM only if it doesn’t double the load.
4. Follow-ups: **FU1 ~day 4**, **FU2 ~day 9**, then close.
5. Pipeline: Maps scrape → AI prequalify → **you QA** → sheet → draft → **you send**.
