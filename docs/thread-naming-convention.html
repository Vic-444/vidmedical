Cursor nerve centers

Thread naming convention

Two paths (VidMedical and Upwork). Same naming grammar. Open a thread only when you need that desk.

Formula

Path first, desk second. Optional client or channel later.

[Path] - [Desk]
[Path] - [ClientName]
[Path] - [Channel]  (only if it earns its own desk)

The two paths

VidMedical

Short: VM · Domain: vidmedical.com

  • VidMedical - Business start here Studio strategy, site, offer, content, systems, hiring SOPs. This chat.
  • VidMedical - Workplace when needed Make the work: briefs, AE/C4D, revisions, delivery for VM retainers / template builds.
  • VidMedical - YouTube later Only if YouTube becomes its own machine. Until then, keep content inside Business.
  • VidMedical - [Client] later One thread per concurrent VM client when volume or confidentiality needs a split.

Upwork

Short: UW · Freelance line

  • Upwork - Business BD / intake Job search, proposals, profile, invites, scoping. Past proposal archive lives here.
  • Upwork - Workplace production Active freelance delivery: briefs, AE/C4D, revisions, handoff.
  • Upwork - [Client] later Split from Workplace when multiple clients run at once or NDAs demand isolation.

What each desk is for

  • Business — grow/run the line (offer, site, content, BD, systems). Does not open the project file.
  • Workplace — make the work (briefs → AE/C4D → revisions → delivery). Does not write the homepage.
  • Client thread — same as Workplace, scoped to one engagement.

Clarity rule

Business never opens the project file; Workplace never writes the homepage. If a chat starts doing both, move the task or split the thread.

When to open what

  • Start with threads you need now — not the full map.
  • Early set that usually makes sense: VidMedical - Business, Upwork - Business, Upwork - Workplace.
  • Add VidMedical - Workplace when the first VM client (or serious production/SOP build) shows up.
  • Add YouTube / per-client threads only when concurrency or focus demands it.
  • New threads start fresh. Seed each with a short purpose + the artifacts for that desk only (not this whole history).

Metaphor (optional)

One drive (you + Cursor). Separate folders so work doesn’t mix. Each folder can have “hands” (MCPs / tools) for what’s inside it — Upwork MCP on BD, AE/C4D on Workplace, light or none on Business.
